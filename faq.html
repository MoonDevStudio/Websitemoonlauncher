Good questions, clear answers

The details, without the guesswork.

Answers are based on the public Moon Launcher project notes. Product support can differ between desktop and Android builds.

What is Moon Launcher?
Moon Launcher is a project building platform-specific launchers for Minecraft Java. Windows and Linux builds are available; the Android version is in development and is not available to download yet.
Is Moon Launcher free?
The project publishes public release assets on GitHub. No separate pricing or payment model is documented in the public project notes. Use the official Download page.
Does it support Minecraft Java Edition?
Yes. Minecraft Java is the target of the launcher. Available versions and behavior depend on the platform build and its release notes.
Does Moon Launcher support Fabric?
Fabric support is not confirmed in the public build notes currently available to this website. Check the release notes for the exact build before relying on it.
Does Moon Launcher support Forge or NeoForge?
Dedicated Forge and NeoForge installation flows are not confirmed in the public notes. Catalog access for mods does not by itself confirm mod-loader support.
How do I download Moon Launcher?
Choose Windows or Linux on the Download page. Android is still in development and has no download button. Desktop download buttons appear only for official public release assets.
How do I report a bug?
Open a report in GitHub Issues. Include your operating system, launcher release tag, and reproduction steps. Never include passwords, tokens, or private account data.
Can I download the Android version?
Not yet. Android is in development and cannot be downloaded from this website.
Is Moon Launcher affiliated with Mojang or Microsoft?
No. Moon Launcher is an independent project and is not affiliated with Mojang Studios or Microsoft. Minecraft is a trademark of Mojang Studios.
