Introduction

Moon Launcher distributes platform-specific builds intended to make Minecraft Java setup and management more approachable. Windows and Linux releases use a desktop XMCL runtime. Android support is in development and is not available to download from this website.

The legacy web shell in the launcher repository is not the Windows/Linux application and does not launch Minecraft. The website and launcher app are separate projects.

Installation

Windows

Download the official x64 installer from the Download page. Beta builds may be unsigned and can trigger a Windows SmartScreen warning. Only run installers you downloaded from the official GitHub Releases.

Linux

Download the official x64 AppImage. The project notes that Linux builds are unsigned. Follow the AppImage execution guidance for your distribution and review release-specific notes.

Android

The Android version is in development. There is no Android installer available to download from this website yet.

First launch

  1. Install a Windows or Linux build from the official release page.
  2. Open the launcher and choose an account option available in that build.
  3. Choose a Minecraft version or instance using the controls provided by that platform release.
  4. Review the release notes if a menu or option differs from this guide.

Android remains in development; setup steps will be documented when a public build is available.

System requirements

  • Windows: Windows 10 version 1903 or later, or Windows 11; x64.
  • Linux: x64 AppImage release.
  • Android: requirements will be published when Android development is ready for release. No installer is currently available.

Other memory, graphics, and storage requirements depend on Minecraft, mods, and the device. The project does not publish a single minimum specification for all setups.

Minecraft versions

Desktop releases use XMCL-based version and instance management. Java runtime selection is documented for compatible Java 17, 21, and 25 versions, with legacy Minecraft versions retaining their own Java requirements.

Availability of a specific Minecraft version is determined by the selected build and its upstream metadata. Consult the release notes if a version is missing.

Game profiles

Desktop release notes describe instances and installed-content management. Use the launcher’s current instance controls to organize separate game setups. Feature names can differ by release.

Android is in development. Its profile behavior and release requirements have not been published for public download.

Game directory

Custom game-directory behavior is not fully documented in the available project notes. Check the settings and release documentation in the exact build you use. Back up worlds and configuration before changing directories.

Installing Fabric, Forge, and NeoForge

The public release notes available to this website do not confirm dedicated Fabric, Forge, or NeoForge installation flows. Vanilla is the Minecraft Java baseline; do not infer loader support from mod catalog access alone.

Check the feature status and the selected build’s release notes for confirmation before installing a loader.

Installing mods and modpacks

Windows and Linux builds use Modrinth and CurseForge catalogs, with Modrinth as a fallback if CurseForge is unavailable. Desktop release notes document `.mrpack` import on Windows. The precise import and install controls depend on the build.

Use content compatible with your Minecraft version and any loader actually supported by your selected instance.

Installing resource packs

Desktop release notes document Modrinth shortcuts for resource packs and installed-content management. Select content that matches your Minecraft version. Android-specific resource pack controls are not documented here.

Installing shaders

Desktop release notes document catalog shortcuts for shaders. The public notes do not fully specify shader loader requirements or Android behavior. Check the selected release and Minecraft version before installing a shader pack.

Microsoft account login

Account choices differ by build. Windows release notes list Microsoft, offline, Ely.by, LittleSkin quick choices, and additional Yggdrasil services through its service manager. Android support is in development and cannot currently be downloaded from this website.

Microsoft login requires an OAuth application configured by the launcher project. Sign-in availability may depend on the current release configuration.

Account troubleshooting

  • Confirm that the selected build lists the account provider you want.
  • Check your network connection and system date/time.
  • For Microsoft login errors, retry after the browser sign-in flow and consult the release notes.
  • Android is in development; account setup guidance will be updated when a public Android release is available.

Installation errors

Re-download a desktop installer from the official release and compare the file name against the published asset. Windows beta installers may be unsigned. Linux AppImages are unsigned according to project notes. Android is not available to download from this website.

Do not disable operating-system protections for files from unofficial sources.

Launch errors

Restart the launcher, confirm the selected Minecraft version and instance, and check the current release notes. If the error continues, report the exact build tag, operating system, and error text through GitHub Issues. Do not include passwords or tokens.

Java runtime issues

Desktop builds document automatic selection of compatible Java 17, 21, and 25 runtimes for supported Minecraft versions; legacy versions keep their own requirements. If startup fails, record the Minecraft version and the runtime reported by the launcher, then check the release notes or open an issue.

Common problems

  • Download not found: verify that the desktop release still exists and that the platform asset is published.
  • Different controls: Windows and Linux builds are distinct from Android, which remains in development.
  • Mod catalog unavailable: the desktop build documents Modrinth fallback if CurseForge is unavailable.
  • Need help: include your OS, release tag, and steps to reproduce in a GitHub issue. Remove personal data from logs first.
