The project behind the launcher

Independent by design.
Built in the open.

Moon Launcher is a community software project focused on making Minecraft Java setup and management more approachable across desktop builds, with Android in development.

Mission

Make the path into a Minecraft Java world feel clearer: discover an official build, set up a game instance, and manage supported content from one launcher.

Vision

Grow a launcher ecosystem where platform differences are easy to understand, releases stay open, and every capability is grounded in real builds.

Development philosophy

Publish real release files, describe platform differences honestly, and keep project development visible through GitHub. Capabilities are tied to the actual launcher build, not promises made by this website.
