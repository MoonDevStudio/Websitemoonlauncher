Capabilities by build

A launcher that gives your setup more room.

Moon Launcher ships platform-specific builds. This page separates documented capabilities from features that still need confirmation in release notes.

Version management

Choose and organize Minecraft versions for your desktop game instances. Compatible Java runtimes are selected for supported game versions.

Desktop builds

Mods & modpacks

Windows and Linux builds connect to Modrinth and CurseForge catalogs, with Modrinth available as fallback. Windows notes document `.mrpack` import.

Windows / Linux

Resource packs

Desktop releases document catalog shortcuts and installed-content management for resource packs.

Windows / Linux

Shaders

Shader catalog shortcuts and installed-content management are documented for the desktop builds.

Windows / Linux

Profiles & instances

Desktop releases organize game instances and let you manage installed content within the launcher dashboard.

Desktop builds

Account flows

Windows documents Microsoft, offline, Ely.by, and LittleSkin options. Android support is in development and is not downloadable yet.

Platform-specific

Mod loaders

Fabric, Forge, and NeoForge integration is not confirmed in the public build notes available to this website.

Unverified

Game directories

Directory configuration details are not fully described in public notes. Check documentation for your exact build.

Platform-dependent

Installation management

Desktop releases document an instance dashboard and controls for installed content.

Desktop builds

Launcher customization

Customization controls vary by runtime and are not fully specified in public notes.

Check build notes

The website does not make launcher features appear in your installation. Availability is determined by the actual platform build and its release notes.
